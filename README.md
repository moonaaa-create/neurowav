[대시보드 4] : Let’s See a Person
한 명을 기준으로 분석한 데이터 지표
1. (레이더차트 : 이 인물의 총합 평균치를 계산하여 5 각형을 그린다)
2. (1 인물) – (5 감정) – (2 트랙)
: 이 인물은 가장 스트레스 받은 것이 바로 이 #번 트랙, “~~”다
: 이 인물이 가장 스트레스 받지 않은 것이 바로 이#번 트랙, “~~”다
고로 이 인물은 해당 장르에서 이런 반응을 보여 취향이 아니다 등
3. 기능 이미지 : 인물을 누르면 해당 인물의 데이터로 변하고, 감정 버튼도 삽입하여 4*5
규격의 버튼을 제작 (음악 런치패드 같은 느낌)
*기능이 가장 많을 것 이며 제일 작업 많이 들어가는 페이지
